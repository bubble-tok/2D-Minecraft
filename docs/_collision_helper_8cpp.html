The hasHeadroomAbove function checks whether there is open space directly above the entity.

The hasHeadroomAbove function checks whether there is clear space directly above the entity.

The hasHeadroomAbove function checks the tiles above the left and right sides of the entity. The function returns false if solid terrain blocks the space above.

Parameters
pxThe px parameter represents the x-position of the entity.
pyThe py parameter represents the y-position of the entity.
mapThe map parameter represents the TileMap used for collision checks.
Returns
The function returns true if the space above the entity is clear, and false if solid tiles block the space.

The resolveTileCollision function resolves tile collisions for an entity using separate vertical and horizontal passes.

The resolveTileCollision function resolves AABB tile collisions for a moving entity in two passes.

The resolveTileCollision function first resolves vertical overlap so the entity can land on floors or hit ceilings correctly. The resolveTileCollision function then resolves horizontal overlap so the entity does not pass through walls.

Parameters
pxThe px parameter stores the x-position of the entity and is updated during collision resolution.

vyThe vy parameter stores the vertical velocity of the entity and is updated during collision resolution.
